bazi.calendar.hko_data.decoder¶

读取随包 HKO 节气与阴历二进制表。

JieqiDates 与 DecodedLunarYears 提供解码后的数据，不负责下载或生成文件。 两个后端共用 bazi.calendar.dates 中定义的 LunarYearInfo。 也可继续从本模块导入，取得的是同一个类型。
