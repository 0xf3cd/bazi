bazi.calendar.celestial_data.loader¶

读取 SCHEMA.md 所述的预生成 celestial-calendar 表。

加载层只解析、校验表并按键查询，不解释八字历法语义；上层 CelestialCalendarUtils 负责历法查询，使数据格式或来源变更与历法语义分开。 运行时只用纯 Python 读取已提交表，不导入离线生成器所用的 celestial-calendar 包。
