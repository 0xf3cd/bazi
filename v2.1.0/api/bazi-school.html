bazi.school¶

命盘配置 BaziConfig、流派分歧声明 BaziSchool / DayRollover / Anchor， 以及出生精度和大运年份投影选项 BaziPrecision / DayunYearRule。

class bazi.school.BaziPrecision(*values)[源代码]¶

出生精度，决定排盘时比较出生与节气的粒度。以立春换年，以十二节换月， 所以同日出生也可有不同年/月柱。

出生按「已知的粒度」与节气时刻比较，birth >= jieqi 归新年 / 新月，相等归新。 这是同一规则的三个粒度，不是对同一真值的三种估计。

  • DAY：只知道日期，比到日。

  • HOUR：知道时辰，比到日期与时辰；时辰为两小时，子时始于 23:00，不是单个钟表小时。

  • MINUTE：知道到分，比到日期、小时与分钟。

Examples:

celestial 后端的 2000 年立春为 2000-02-04 20:40:23，HKO 只提供日期。

  • DAY：02-04 全天取年柱庚辰、月支寅，包括 20:40:23 之前；02-03 取己卯、丑。

  • HOUR：戌时 [19:00, 21:00) 与节同一时辰，取庚辰、寅；酉时 [17:00, 19:00) 及当日更早时辰取己卯、丑。

  • MINUTE：20:40 起取庚辰、寅，之前取己卯、丑。

2017 年立春为 2017-02-03 23:34:03，尽管当日约 98% 的时间在交节之前，DAY 仍将全天归新。 DAY 调用方没有声明知道钟表时刻，不能据未知时刻改变归属或干支月长。

子时跨午夜，相等时辰窗口可始于前一公历日：2009 年立春为 2009-02-04 00:49:48， 所属子时始于 02-03 23:00，因此 HOUR 的 02-03 23:30 归新，DAY 的同日却归旧。 三档不构成嵌套细化。

HOUR 与 MINUTE 需要真实节时刻；Bazi.__init__ 拒绝这两档使用 HKO， 因为它的 jieqi_moment 只有午夜占位，见 CalendarUtilsProtocol。

class bazi.school.DayunYearRule(*values)[源代码]¶

把每个精确大运边界投影为年份标签的规则。

  • JIE_PROJECTED：逐个边界按所属节投影干支年；首步标签不早于命盘按精度归属的出生年。

  • FIXED_DECADE：从共享首标签起按传统固定十年排表；后续标签表示年表位次，不保证是边界所在干支年。

class bazi.school.DayRollover(*values)[源代码]¶

日柱换日点的流派分歧。

  • WAN_ZISHI（晚子时）：23:00 子时一开始即换日柱，[23:00, 24:00) 取次日日柱。 默认采用此多数派读法，行为由 test_bazi 验证。

  • ZIZHENG（子正）：00:00 才换日柱，子时按民用日期取日柱，不提前换。

Note:

  • 年/月柱独立按 BaziPrecision 比较节时刻，相等归新。WAN_ZISHI 的 23:30 出生取次日日柱， 不使年/月归属随之改变。

不修改既有定义；新读法须另加定义。

class bazi.school.PeiouXingDef(*values)[源代码]¶

配偶星取法的流派分歧。

  • ZHENGCAI_ZHENGGUAN：男命取正财干、女命取正官干。默认。

  • YINYANGGAN：《三命通会·卷七·论六亲》读法：男命取我所克五行中的阴干，女命取克我五行中的阳干。 书证直例仅甲、乙两干的男女四格；其余十六格按「其餘八干俱以類推」与「陽男陰女」原则类推重建，单源，未获第二独立来源。

Note:

  • 两读在阳男、阴女十格上目标相同，在阴男、阳女十格上不同；每个（日主，性别）仍恰有一个目标天干。

  • 地支侧均取主气等于目标天干的地支。

  • 不修改既有定义；新读法须另加定义。

class bazi.school.Anchor(*values)[源代码]¶

神煞查法所锚的柱位（流派分歧处）。

  • YEAR：以年柱为锚。

  • DAY：以日柱为锚。

  • YEAR_AND_DAY：年、日两柱分别为锚，各查一遍。

成员只指定锚柱；取该柱天干还是地支由神煞自身的查法决定，记录在分析层注册表中。 _ANCHOR_CHOICES 按字段列出支持的取值及出处或已知出处缺口，BaziSchool 拒绝表外取值。

不修改既有定义；新读法须另加定义。

class bazi.school.BaziConfig(precision=BaziPrecision.DAY, backend=CalendarBackend.CELESTIAL, school=BaziSchool(), dayun_year_rule=DayunYearRule.JIE_PROJECTED)[源代码]¶

命盘级不可变配置，包括出生精度、历法后端、大运年份投影及求值时读取的流派档案。 Bazi 持有整个配置，配置参与相等性与 JSON。大运年份投影虽不改变四柱与大运物理时刻线， 仍属于命盘身份；相等配置的哈希相等。

Args:

  • precision: (BaziPrecision) 出生时间精度。

  • backend: (CalendarBackend) 所有历法换算所用的后端。

  • school: (BaziSchool) 流派档案，默认 DEFAULT_SCHOOL。

  • dayun_year_rule: (DayunYearRule) 默认大运年份投影。

Note:

  • 性别不影响本配置所聚合的四柱计算，仍由 Bazi.create 接收并解析字符串。

  • 构造只收声明类型，字符串解析由 from_values 提供。

参数:

  • precision (BaziPrecision)

  • backend (CalendarBackend)

  • school (BaziSchool)

  • dayun_year_rule (DayunYearRule)
