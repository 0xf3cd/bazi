bazi.utils.bazi_utils¶

排盘所用的干支、十神、藏干、纳音与十二长生计算。

各函数接收相应领域值；组合成完整命盘使用 Bazi 与 BaziChart。

bazi.utils.bazi_utils.shishen(day_master, other)[源代码]¶

输入日主和某天干或者地支，返回天干或地支对应的十神。

Args:

  • day_master: (Tiangan) 日主天干。

  • other: (Tiangan | Dizhi) 待查天干或地支；地支取主气。

Return: (Shishen) 对应十神。

Examples:

  • shishen(Tiangan("甲"), Tiangan("甲")) -> Shishen("比肩") # 甲为甲的比肩。

  • shishen(Tiangan("甲"), Dizhi("寅")) -> Shishen("比肩") # 寅为甲的比肩。

  • shishen(Tiangan("壬"), Dizhi("戌")) -> Shishen("七杀") # 戌为壬的七杀。

参数:

  • day_master (Tiangan)

  • other (Tiangan | Dizhi)

返回类型:

Shishen

bazi.utils.bazi_utils.nayin_str(gz)[源代码]¶

返回六十甲子干支对应的纳音；不属于六十甲子的组合抛出 ValueError。 Ganzhi 本身允许全部 120 种天干、地支组合，本入口单独检查纳音的适用性。

Args:

  • gz: (Ganzhi) 待查纳音的干支。

Return: (str) 对应的纳音。

Examples:

  • nayin_str(Ganzhi.from_str("甲子")) -> "海中金"

参数:

gz (Ganzhi)

返回类型:

str
