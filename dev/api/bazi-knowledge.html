知识整理状态，不是命盘判别结果。 unconditional：无命盘前提；described：已记录前提文字，术语可能尚无计算定义； unresolved：前提仍待重建。

Literal['unconditional', 'described', 'unresolved'] 的别名

bazi.knowledge.SourceState[源代码]¶

条目的来源状态，与前提整理状态和输出资格分别记录。 witnessed：记录为已核定的原文出处；editorial：原作说明； unverified：来源尚未核定，条目不绑定来源见证；repository_attributed：仓内规则实现的归属。 这些标记不表示命盘前提已满足，也不认证现实事件。

Literal['witnessed', 'editorial', 'unverified', 'repository_attributed'] 的别名

class bazi.knowledge.KnowledgeBase(objects, contexts, sources, entries)[源代码]¶

校验、索引、查询并导出不可变解释条目。

Note:

  • JSON 为编辑来源；索引与导出由它生成。

  • 值比较与 hash 包含四份注册表的内容及顺序，不依赖实例身份。

  • sources 包含完整来源注册表，包括未被条目引用的记录；直接读取 sources[source_id] 查来源，query(source_id=...) 查关联条目。

  • 仅供参考条目不判断命盘适用性。条目的 sources 为空或署名注明出处未核， 均不表示无来源或断言为假；仓内署名也不等于已经核定的古籍见证。

参数:

  • objects (tuple[KnowledgeObject, ...])

  • contexts (tuple[KnowledgeContext, ...])

  • sources (tuple[KnowledgeSource, ...])
