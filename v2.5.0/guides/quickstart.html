快速开始¶

这一页带你排出第一张盘，读出四柱，并指出下一步该去哪一页。

安装¶

需要 Python 3.11 或更高版本。在独立环境中安装；如果还不熟悉环境创建和终端操作，先按 README 的准备步骤操作。

python -m pip install bazi

运行时只用标准库和随包数据，不联网。普通使用不需要测试或文档构建工具。

本页说明对应当前开发源码。已发布版本的接口以该版本 tag 下的文档为准，两者可能不同。

备注

本库没有 from bazi import Bazi 这样的根类，请从定义模块导入，下面每个示例都这样写。 终端操作可安装当前开发版的 bazi 命令，发布版暂未包含；安装与用法见 README。

排第一张盘¶

示例用虚构的出生时间，按东八区（UTC+8）公历钟填写无时区 datetime。默认入口的年月与东八区节气表比较，日时按输入的钟读取，不自动换算时区；海外当地钟的限制见 配置与时间口径。BaziChart 在 Bazi 之上提供十神、大运等派生信息。

from datetime import datetime

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart

bazi = Bazi.create(datetime(1990, 5, 17, 10, 30), 'female')
chart = BaziChart(bazi)

print('四柱', ' '.join(str(pillar) for pillar in bazi.pillars))
print('日主', bazi.day_master)
print('性别', bazi.gender)
print('精度与后端', bazi.config.precision, bazi.config.backend)

四柱 庚午 辛巳 壬午 乙巳
日主 壬
性别 female
精度与后端 day celestial

把上面的程序保存为 UTF-8 文件 show_chart.py，不要取名为 bazi.py。在终端进入该文件所在目录，使用刚才安装包的同一个环境运行：

python show_chart.py

把 datetime(1990, 5, 17, 10, 30) 换成上面口径的公历出生钟时，female 为女、male 为男。本例没有经度，不换算真太阳时；地点盘与海外当地钟的使用边界见 配置与时间口径，不要把时区转换与真太阳时当成同一个操作。

  • bazi.pillars 依次是年、月、日、时柱，每柱是一个 Ganzhi。

  • 性别字符串接受 男、女、male、female；str(bazi.gender) 为拉丁写法。

  • 藏干十神显示为单字简称，如财、才、官、杀；完整名称见 Shishen，每个十神的简称由 abbr 取得。

  • 通过 bazi.config 读取配置；派生值由 chart 的属性取得，见 集成开发。

把盘排成文本¶

模块 bazi.chart_text 的函数把命盘排成可读的纯文本：不写文件，不依赖终端着色库，同一张盘每次得到同样的文字。 basic_text 给出日元、出生时刻，以及四柱各自的十神、阴阳五行、藏干、纳音和十二长生。

from datetime import datetime

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.chart_text import basic_text

chart = BaziChart(Bazi.create(datetime(1990, 5, 17, 10, 30), 'female'))
print(basic_text(chart).strip())

  • 流运文本把流年的数量交给调用方，见 关系与流运；要加终端颜色，见 集成开发。

保存结果¶

下面的保存例子与 README 的 first_chart.py 排同一张盘，可独立另存为 save_chart.py。在该文件所在目录运行 python save_chart.py 后，打开 chart.txt 看基本命盘。路径相对运行命令时的当前目录，重复运行会覆盖同名文件，需保留的旧结果请先另存。

from datetime import datetime
from pathlib import Path

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.chart_text import basic_text

chart = BaziChart(Bazi.create(datetime(1990, 5, 17, 10, 30), 'female'))
text_path = Path('chart.txt')
text_path.write_text(basic_text(chart), encoding='utf-8')
print(text_path)

chart.txt

本库不提供命盘保存恢复接口。安装后的 bazi chart 也可保存 TXT，运行位置与输出路径见 README 命令行说明。

在交互里看一眼¶

在 Python 交互环境里直接输入对象，会看到一行摘要：出生时刻、性别和四柱。配置不是默认值，或是地点盘时，摘要才会多出对应部分。 摘要不会去算流运，也不展开整张盘；它只用来探索和调试，格式以后可能调整，不应被程序解析。

from datetime import datetime

import bazi
from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.transit_chart import TransitChart

chart = BaziChart(Bazi.create(datetime(1990, 5, 17, 10, 30), 'female'))
print(repr(chart))
print([name for name in dir(bazi) if name in ('knowledge', 'transit_chart')])

try:
  TransitChart(chart.bazi)
except TypeError as error:
  print(error)

try:
  bazi.Bazi
except AttributeError as error:
  print(error)

BaziChart(Bazi(1990-05-17T10:30:00, female, 庚午 辛巳 壬午 乙巳))
['knowledge', 'transit_chart']
Expected BaziChart, got <class 'bazi.bazi.Bazi'>; wrap it with BaziChart(bazi)
module 'bazi' has no attribute 'Bazi'; use: from bazi.bazi import Bazi

dir(bazi) 会列出按需导入的子模块，导入后才加载它们；上面只筛出了其中两个，实际的列表更长。传错对象时，报错在原来的“期望什么，收到什么”之后，接着说明该用哪个入口。

默认值是一种选定的口径¶

没有传配置时，库使用 DAY 精度、celestial 历法后端，晚子时 23:00 换日柱，以立春换年。 这是本库选定的一套取法，不是八字唯一的读法：精度、历法后端和流派取法各有其他选项。

出生在交节日前后、子时前后，或要采用其他流派时，先读 配置与时间口径，再决定要不要改默认值。

下一步¶

排好一张盘之后，常用的三条路径如下。示例仍按上文的东八区钟填写出生输入，每段都可独立运行。

查某一年的流年¶

from datetime import datetime

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.transit_chart import TransitChart

chart = BaziChart(Bazi.create(datetime(1990, 5, 17, 10, 30), 'female'))
year = TransitChart(chart).at_year(2024)
if year is not None:
  print(year.liunian)

甲辰

2024 是干支年标签；at_year 在出生干支年之前返回 None，所以先检查再取字段。 返回的 TransitSet 也可包含小运或大运，缺项为 None。流月、日期、时刻及原局关系查询见 关系与流运。

只取需要的几个流年¶

from datetime import datetime
from itertools import islice

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart

chart = BaziChart(Bazi.create(datetime(1990, 5, 17, 10, 30), 'female'))
for year in islice(chart.liunian, 3):
  print(year.ganzhi_year, year.ganzhi)

1990 庚午
1991 辛未
1992 壬申

这里取出生干支年起的前三年。chart.liunian 可无限延续，不要直接转成 list 或 tuple； 每次访问该属性都会新建生成器；将生成器存到变量后，再次迭代会从上次停止的位置继续。 有限大运和流年文字的用法见 关系与流运。

检查一项结构前提¶

from datetime import datetime

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.context_matching import NatalObservation, evaluate_context

chart = BaziChart(Bazi.create(datetime(1990, 5, 17, 10, 30), 'female'))
result = evaluate_context(
  chart,
  criterion_id='editorial.guansha_coexistence.v1',
  observation=NatalObservation(),
)
print(result.criterion.status, result.criterion.scope_complete)

SATISFIED True

本例只查原局，结果表示“正官与七杀各至少出现一次”这一结构前提满足，观察范围完整。 它不是旺衰、格局或现实事件的判断，也不证明知识条文本身为真。证据、参考条目和其他观察范围见 集成开发； 不排盘而查文字与出处，见 查阅知识库。

  • 选择精度、换日点、大运年份口径或真太阳时：配置与时间口径。

  • 旧调用与脚本的升级条件：发布说明。

逐个类和方法的签名在 API 参考中，入口见 Bazi 和 BaziChart。
