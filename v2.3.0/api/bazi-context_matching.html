class bazi.context_matching.CriterionInfo(criterion_id, definition, profile_type, entry_role, observation_keys, required_gender, claim_ids, claim_genders)[源代码]¶

判据的不可变查阅目录，不是一次命盘判别，也不认证条目适用于现实事件。

Note:

  • premise 判关联条目的完整前提，condition 只判局部事实，不能据此认定条目全文前提成立。

  • claim_ids 是默认语料的约定，不保证自定义知识库有这些条目。绑定识别核对条目及其引用的 对象、情境、来源记录的内容摘要，不以相同 ID 认证内容，也不认证条文真伪或现实适用性。

  • required_gender 是判据门槛：仅 editorial.guansha_coexistence_female.v1 要求女命，范围完整时 男命得到 NOT_SATISFIED/female_gate_false。claim_genders 只限制关联条目；两条男命婚恋条目 不向女命返回，不改变事实判别。普通官杀并见判据没有性别门槛。

  • observation_keys 在两个官杀判据中都保留 female，是否有性别门槛另由 required_gender 表示。

  • 直接构造只检查目录值的形状，不认证自填说明；已注册目录请从 criterion／criteria 取得。

bazi.context_matching.evaluate_context(chart, *, criterion_id, profile, knowledge=None, include_reference_only=False)[源代码]¶

检查选定范围是否满足已注册判据，返回判别、观察、证据及条目的匹配结果。

Note:

  • 婚恋判据走 RelationshipProfile，按 spouse_evidence 计算结构证据；其余判据走 ContextProfile。判据与 profile 种类不符抛 ValueError。

  • 官杀两条判据判别关联条目的完整前提。其余判据只判可计算事实：婚恋两条判结构，丁火、 庚金两条判日主，偏印、枭印两条判十神是否出现。身弱、有制有化、喜用、夺食、「有用／ 喜忌／成格」等完整理论条件留在知识文本，不为它们新增 UNKNOWN，也不认证其已满足； 所需流年缺失或不可查询时返回 UNKNOWN。

  • 参考条目须显式设置 include_reference_only=True。条件判据的关联条目只是条件参考， 与事实判别的状态无关；只向男命返回的关联条目对女命一律不关联（门槛先于绑定状态），静态查阅不受限。

  • 未传 knowledge 时，每次独立加载默认来源，已保存的修改在后续加载时可见； 传入知识库则直接复用。已有知识库和结果保留原内容，共享调用须显式重载才能取得更新。

  • 观察原局年、月、时明干与四支全部实际藏干；请求流年时加入该流年明干与藏干。 不观察日主明干，但等于日主的藏干仍分类为比肩；藏干百分比不作权重，重复位置保留。 不另加力量／次数阈值、相邻、去留或有效制化条件。

  • 范围完整性优先于女命条件与事实判别：男命缺必需年份仍为 UNKNOWN / missing_transit_coordinate。 婚恋范围缺查询坐标为 UNKNOWN / missing_transit_coordinate；入口不可查询或所求种类 部分缺失为 UNKNOWN / transit_unavailable，已取得种类的证据照常保留。 SATISFIED / NOT_SATISFIED 只描述完整的显式前提，不证明现实事件成立。

  • 官杀判据关联的四条原作知识均仅供参考；自定义库若改变同 ID 的条目、对象、 前提、情境、来源或输出政策，该条返回 binding_unrecognized。条件参考同样核对绑定， 不一致时记 recognized=False，不改变事实判别。等值的导出重载条目仍可匹配。

  • 未选择参考条目或知识库中缺少相应条目时，不生成其 EntryMatch 或 RelatedEntry。 前提满足不授予默认输出资格。

Return: (ContextResult) 判据结果、逐柱观察或结构证据、条目匹配，以及输入与知识快照。
