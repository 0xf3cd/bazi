class bazi.knowledge.KnowledgeBase(objects: tuple[KnowledgeObject, ...], sources: tuple[KnowledgeSource, ...], entries: tuple[KnowledgeEntry, ...])[源代码]¶

加载、查询并渲染不可变知识条目。

Note:

  • JSON 是编辑源；加载只校验结构与引用，不要求独立来源数量，不认定条目适用于某盘。

  • 对象、来源、条目的内容与顺序参与相等和哈希。来源注册表可以包含尚未引用的记录。

  • 原创署名与文献引用分别填写；没有引用不表示断言为假，署名也不等于已核定的古籍见证。

读取并校验知识 JSON；省略路径时读取随包语料。

render(entry: KnowledgeEntry, *, show_sources: bool = False) → str[源代码]¶

显示条目、必要前提／限度、读法、署名及简短出处；空栏目省略。

show_sources=True 另展开定位、原引文及支持范围。来源的必要说明始终显示， 不因关闭详情而隐藏正文／夹注的区别或证据限度。本方法不求值命盘前提。
