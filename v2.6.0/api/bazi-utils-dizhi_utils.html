bazi.utils.dizhi_utils¶

地支关系判断、搜索与组合发现。

discover 处理地支，discover_ganzhis 保留干支与柱位；definitions 参数选择关系读法。

class bazi.utils.dizhi_utils.DizhiRelationDiscovery(data: Mapping[FrozenDictKeyType, FrozenDictValueType])[源代码]¶

以地支关系为键、以满足该关系的地支组合元组为值的冻结映射。 每个组合是 frozenset[Dizhi]，只保存参与的地支值，不保存柱位。

拱合、拱会的组合只含两个实支。要取得所拱的第三支，分别把这两支传给 gonghe、gonghui。 干支查询的 gong_def 包含完整成立条件，gonghe 的 definition 只选择拱合的结构范围。 用 DizhiRules.GONG_GONGHE_SCOPE[gong_def] 取得与原查询一致的范围，再查第三支。

Examples:

from bazi.defines import Dizhi
from bazi.rules import DizhiRules
from bazi.utils.dizhi_utils import gonghe

gong_def = DizhiRules.GongDef.SAME_STEM_WIDE
scope = DizhiRules.GONG_GONGHE_SCOPE[gong_def]
assert gonghe(Dizhi.申, Dizhi.子, definition=scope) is Dizhi.辰
filter(f: Callable[[RelationType, frozenset[RelationItemType]], bool]) → Self[源代码]¶

merge(other: Self) → Self[源代码]¶

合并两个发现结果；关系键与组合都按左侧、右侧的首次出现顺序保留，重复组合去重。

mutual_only(items1: Set[RelationItemType], items2: Set[RelationItemType]) → Self[源代码]¶

只保留与两侧值集均相交的组合；与任一侧不相交即单侧组合。

Note: 按值判定，不追踪具体出现：组合全由单侧凑成，只要另一侧也有相同值，就会被保留。 discover_mutual([子, 丑], [子]) 仍保留六合{子,丑}（子出现在两侧值集里，尽管一侧就够凑）。

bazi.utils.dizhi_utils.xing(*dizhis: Dizhi, definition: XingDef = DizhiRules.XingDef.LOOSE) → XingSubType | None[源代码]¶

检查输入的地支是否刚好构成相刑关系。 相刑关系的看法有多种，默认使用 DizhiRules.XingDef.LOOSE。 如果使用 DizhiRules.XingDef.LOOSE，则 dizhis 的顺序会影响结果。 如果使用 DizhiRules.XingDef.STRICT，则 dizhis 的顺序不会影响结果。

Note:

  • dizhis 的最大长度为 3，超过时抛出 ValueError。

Args:

  • *dizhis: (Dizhi) 待查地支。

  • definition: (DizhiRules.XingDef) 相刑的定义。

Return: (DizhiRules.XingSubType | None) 相刑类型；不构成相刑时返回 None。

Examples:

from bazi.defines import Dizhi
from bazi.rules import DizhiRules
from bazi.utils.dizhi_utils import xing

assert xing(Dizhi.寅, Dizhi.巳, Dizhi.申) is DizhiRules.XingSubType.SANXING
assert xing(Dizhi.寅, Dizhi.巳, definition=DizhiRules.XingDef.STRICT) is None
assert xing(Dizhi.寅, Dizhi.巳, definition=DizhiRules.XingDef.LOOSE) is DizhiRules.XingSubType.SANXING
assert xing(Dizhi.午) is None
assert xing(Dizhi.午, Dizhi.午) is DizhiRules.XingSubType.ZIXING
assert xing(Dizhi.午, definition=DizhiRules.XingDef.LOOSE) is None
for branches in ([Dizhi.寅, Dizhi.巳, Dizhi.申, Dizhi.午], [Dizhi.寅, Dizhi.巳, Dizhi.申, Dizhi.午, Dizhi.午]):
  try:
    xing(*branches)
  except ValueError:
    pass
  else:
    raise AssertionError('超过三个地支应抛出 ValueError')

bazi.utils.dizhi_utils.search(dizhis: Sequence[Dizhi], relation: DizhiRelation, *, definitions: DizhiRelationDefinitions = DEFAULT_DIZHI_RELATION_DEFINITIONS) → tuple[frozenset[Dizhi], ...][源代码]¶

返回 dizhis 中所有满足该关系的组合。

Note:

  • 只接受 Sequence，非序列在遍历前抛出 TypeError；空序列合法，重复地支保留自刑重数。

  • 组合不含作用方向，合、会本身无向；生、克的方向用 sheng / ke 单独判断。 例如组合 {午, 寅} 本身不表示寅生午或午生寅。

  • 对于刑关系，更复杂一些：

    • 对于辰午酉亥自刑，只需要同时出现两次就满足相刑关系。

    • 对于子卯相刑，只需要子、卯都出现就满足相刑关系。

    • 对于丑未戌、寅巳申三刑，有的看法认为需要三个地支同时出现才算刑，有的看法认为只需要出现两个也算相刑。

    • 用哪个定义由 definitions.xing_def 决定；默认 XingDef.LOOSE 下，丑未戌、寅巳申三取二即算。

    • 需要具体刑类型及方向时用 xing。

  • 拱合、拱会依赖柱位与天干；本纯地支入口对两者抛 ValueError，请用 search_ganzhis。

  • 暗合查询的表由 definitions.anhe_def 选择，默认 DizhiRules.AnheDef.NORMAL_EXTENDED（最宽定义）。

  • 结果顺序：三会、六合、三合、半合按定义序，暗合等集合型关系按组合成员枚举序； 刑按规则表首次组合出现序，生克先按施方、受方枚举序排列，再折为保序去重的无向组合。

Args:

  • dizhis: (Sequence[Dizhi]) 待查地支；重数参与自刑判断。

  • relation: (DizhiRelation) 待查关系。

  • definitions: (DizhiRelationDefinitions) 已校验的关系定义；本入口只读取暗合与刑定义。

Return: (DizhiRelationCombos) 所有匹配组合，不包含作用方向。

Examples:

from bazi.defines import Dizhi, DizhiRelation
from bazi.utils.dizhi_utils import search

assert search([Dizhi.寅, Dizhi.卯, Dizhi.辰, Dizhi.午, Dizhi.未], DizhiRelation.三会) == (
  frozenset({Dizhi.寅, Dizhi.卯, Dizhi.辰}),
)
assert search([Dizhi.寅, Dizhi.卯, Dizhi.丑, Dizhi.午, Dizhi.申], DizhiRelation.暗合) == (
  frozenset({Dizhi.丑, Dizhi.寅}), frozenset({Dizhi.寅, Dizhi.午}), frozenset({Dizhi.卯, Dizhi.申}),
)
branches = [Dizhi.寅, Dizhi.巳, Dizhi.申, Dizhi.辰]
assert search(branches, DizhiRelation.刑) == (
  frozenset({Dizhi.寅, Dizhi.巳, Dizhi.申}), frozenset({Dizhi.寅, Dizhi.巳}),
  frozenset({Dizhi.巳, Dizhi.申}), frozenset({Dizhi.寅, Dizhi.申}),
)
# 单个辰不构成自刑；两个辰构成自刑，但返回的冻结集合只保留一个辰。
assert search(branches + [Dizhi.辰], DizhiRelation.刑) == (
  frozenset({Dizhi.寅, Dizhi.巳, Dizhi.申}), frozenset({Dizhi.辰}),
  frozenset({Dizhi.寅, Dizhi.巳}), frozenset({Dizhi.巳, Dizhi.申}), frozenset({Dizhi.寅, Dizhi.申}),
)
assert search([Dizhi.卯, Dizhi.子, Dizhi.寅, Dizhi.巳], DizhiRelation.刑) == (
  frozenset({Dizhi.子, Dizhi.卯}), frozenset({Dizhi.寅, Dizhi.巳}),
)

bazi.utils.dizhi_utils.search_ganzhis(ganzhis: Sequence[Ganzhi], relation: DizhiRelation, *, definitions: DizhiRelationDefinitions = DEFAULT_DIZHI_RELATION_DEFINITIONS) → tuple[frozenset[GanzhiOccurrence], ...][源代码]¶

找出地支满足 relation 的具体干支位置组合。

输入序列中的零基序号就是具体出现的身份，因此不同位置的相同干支或地支不会混同。 对现有不依赖位置的关系，逐项投影到地支并去重后与 search 完全等价。

拱合、拱会在本入口应用来源档案，只查相邻具体出现；所拱之支已在输入中出现时不再论暗拱。 返回组合只含两个实支；虚支恢复契约见 DizhiRelationDiscovery。

非拱组合先沿 search 的地支组合序，再按输入序号展开同值的多处出现； 拱局按相邻柱位对的顺序返回。

Args:

  • ganzhis: (Sequence[Ganzhi]) 有序干支序列；地支重数参与自刑判断。

  • relation: (DizhiRelation) 待查关系。

  • definitions: (DizhiRelationDefinitions) 关系定义；拱局读取 gong_def，只查相邻具体出现。

Return: (GanzhiRelationCombos) 所有匹配的具体出现组合，不包含作用方向。

bazi.utils.dizhi_utils.discover_ganzhis(ganzhis: Sequence[Ganzhi], *, definitions: DizhiRelationDefinitions = DEFAULT_DIZHI_RELATION_DEFINITIONS, relations: Sequence[DizhiRelation] = tuple(DizhiRelation)) → GanzhiRelationDiscovery[源代码]¶

保留输入位置与天干，发现具体干支之间的所选地支关系。

Note:

  • 没有匹配组合的关系不会出现在返回映射中。

  • 返回的组合不体现有向关系的方向。

  • 拱局的来源档案、相邻、填实与结果形状语义同 search_ganzhis。

  • 关系按 relations 的首次出现顺序求值，重复关系只查一次。

  • 输入须为 Sequence；非序列在遍历前抛出 TypeError。

Args:

  • ganzhis: (Sequence[Ganzhi]) 有序干支序列。

  • definitions: (DizhiRelationDefinitions) 关系定义，原样传给 search_ganzhis。

  • relations: (Sequence[DizhiRelation]) 只求值这些关系，默认全部；空序列不求值任何关系。

Return: (GanzhiRelationDiscovery) 保留具体出现位置的冻结关系映射。

bazi.utils.dizhi_utils.discover_mutual_ganzhis(ganzhis1: Sequence[Ganzhi], ganzhis2: Sequence[Ganzhi], *, definitions: DizhiRelationDefinitions = DEFAULT_DIZHI_RELATION_DEFINITIONS, relations: Sequence[DizhiRelation] = tuple(DizhiRelation)) → GanzhiRelationDiscovery[源代码]¶

发现参与柱横跨两组输入的所选干支关系。

具体出现序号属于概念上的 ganzhis1 + ganzhis2；第二组从 len(ganzhis1) 起算。 跨组拱局按岁运作用口径直接成为候选；单侧内部的拱局不进跨组结果。 所拱之支已在任一组出现时不再论暗拱；组合只含真实参与者，保留完整干支与位置。 拱局组合按左侧柱位优先的两侧柱位对顺序返回；非拱组合沿 search_ganzhis 的查询顺序。

Note:

  • 两组输入都须为 Sequence，在遍历任一组前检查；空序列合法。

  • 关系按 relations 的首次出现顺序求值，重复关系只查一次；没有组合的键不返回。

  • 非拱关系同样要求具体参与者来自两侧，与 discover_mutual 的按值查法不同。

  • 返回的组合不体现有向关系的方向。

Args:

  • ganzhis1: (Sequence[Ganzhi]) 第一组有序干支。

  • ganzhis2: (Sequence[Ganzhi]) 第二组有序干支。

  • definitions: (DizhiRelationDefinitions) 关系定义。

  • relations: (Sequence[DizhiRelation]) 只求值这些关系，默认全部；空序列不求值任何关系。

Return: (GanzhiRelationDiscovery) 参与者横跨两侧的具体出现组合。

bazi.utils.dizhi_utils.discover_mutual(dizhis1: Sequence[Dizhi], dizhis2: Sequence[Dizhi], *, definitions: DizhiRelationDefinitions = DEFAULT_DIZHI_RELATION_DEFINITIONS) → DizhiRelationDiscovery[源代码]¶

找出输入的两组地支中所有可能的关系组合（三会、六合、刑等）。 返回组合须与两组地支值集均相交，不追踪具体出现；按值过滤语义见 RelationDiscovery.mutual_only。

Note:

  • 返回的字典的键中可能不包含所有的 DizhiRelation。

  • 两组输入都须为 Sequence，在遍历任一组前检查；重复地支保留自刑重数。

  • 本纯地支跨组入口不含拱合、拱会；其跨作用域查法见 discover_mutual_ganzhis。

  • 默认定义、选表及组合不保留作用方向的语义见 search。

Args:

  • dizhis1: (Sequence[Dizhi]) 第一组地支。

  • dizhis2: (Sequence[Dizhi]) 第二组地支。

  • definitions: (DizhiRelationDefinitions) 关系定义，原样传给 search。

Return: (DizhiRelationDiscovery) 跨组匹配组合的冻结映射，不包含作用方向。

Examples:

from bazi.defines import Dizhi, DizhiRelation
from bazi.utils.dizhi_utils import DizhiRelationDiscovery, discover_mutual

result = discover_mutual([Dizhi.子], [Dizhi.丑])
assert isinstance(result, DizhiRelationDiscovery)
assert result == {
  DizhiRelation.六合: (frozenset({Dizhi.子, Dizhi.丑}),),
  DizhiRelation.克: (frozenset({Dizhi.子, Dizhi.丑}),),
}
empty = discover_mutual([Dizhi.子, Dizhi.丑], [])
assert isinstance(empty, DizhiRelationDiscovery) and not empty
