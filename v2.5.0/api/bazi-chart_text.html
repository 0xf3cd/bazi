bazi.chart_text¶

命盘与流运的纯文本展示。

basic_text、transit_text 与 chart_text 接收调用方给定的 BaziChart 并返回文本：不写文件， 不依赖终端着色库，固定输入的输出可重放。终端着色由调用方通过 TextStyle 接入，默认纯文本。

class bazi.chart_text.TextStyle(glyph=None, day_master_mark=None)[源代码]¶

给展示文字加样式的钩子；两个字段都不设（None）时原样输出，得到纯文本。

Note:

  • 钩子的返回值原样放进文本，不做检查；版式由调用方负责。

  • 字段既不是 None 也不可调用时抛 TypeError。

Args:

  • glyph: (Callable[[Tiangan | Dizhi], str] | None) 干支字形。收到单个天干或地支， 返回显示文字；干支（Ganzhi）逐字形分别调用。

  • day_master_mark: (Callable[[str], str] | None) 日柱天干十神位置的“日主”标记。

Examples:

  • 不设样式即纯文本：basic_text(chart)。

  • 脚本里用 TextStyle(glyph=colored, day_master_mark=highlight) 接入终端着色。

参数:

  • glyph (Callable[[Tiangan | Dizhi], str] | None)

  • day_master_mark (Callable[[str], str] | None)

bazi.chart_text.basic_text(chart, *, style=None)[源代码]¶

命盘的基本展示：日元、出生时刻、四柱及其十神、阴阳五行、藏干、纳音与十二长生。

Note:

  • 文本以换行开头、换行结尾，可直接 print；地点盘另列民用、真太阳与节气表出生时刻。

Args:

  • chart: (BaziChart) 待展示的命盘。

  • style: (TextStyle | None) 着色钩子；None 为纯文本。

bazi.chart_text.transit_text(chart, *, dayun_count=10, liunian_count=100, style=None)[源代码]¶

命盘的运限展示：出生前后的节、交运时间、大运、小运与流年。

Note:

  • 流年可以无限延续，必须限定数量：大运取前 dayun_count 步，流年取自出生干支年起的 liunian_count 年；小运是有限序列，全部列出。

  • 节与大运区间用节气表时刻（UTC+08:00），地点盘也不采用真太阳时。

  • 出生后没有大运起于历法支持范围内时（如 HKO 后端的 2099 年末出生），抛 ValueError， 与 chart.xiaoyun 一致；basic_text 不受影响。

  • 文本以换行开头、换行结尾，可直接 print。

Args:

  • chart: (BaziChart) 待展示的命盘。

  • dayun_count: (int) 列出的大运步数，不小于 0。

  • liunian_count: (int) 列出的流年数，不小于 0。

  • style: (TextStyle | None) 着色钩子；None 为纯文本。

Return: (str) 纯文本展示。

参数:

  • chart (BaziChart)

  • dayun_count (int)

  • liunian_count (int)

  • style (TextStyle | None)

返回类型:

str
