bazi.utils.tiangan_utils¶

天干关系判断、搜索与组合发现。

he、chong、sheng、ke 判断单组关系，search、discover 与 discover_mutual 查询组合。

merge(other: Self) → Self[源代码]¶

合并两个发现结果；关系键与组合都按左侧、右侧的首次出现顺序保留，重复组合去重。

mutual_only(items1: Set[RelationItemType], items2: Set[RelationItemType]) → Self[源代码]¶

只保留与两侧值集均相交的组合；与任一侧不相交即单侧组合。

Note: 按值判定，不追踪具体出现：组合全由单侧凑成，只要另一侧也有相同值，就会被保留。 discover_mutual([子, 丑], [子]) 仍保留六合{子,丑}（子出现在两侧值集里，尽管一侧就够凑）。

bazi.utils.tiangan_utils.he(tg1: Tiangan, tg2: Tiangan) → Wuxing | None[源代码]¶

按无向相合关系查对应五行。 本函数不判断实际合化条件；能否合化仍须结合原盘。

Args:

  • tg1: (Tiangan) 第一天干。

  • tg2: (Tiangan) 第二天干。

Return: (Wuxing | None) 合所对应的五行；不相合时为 None。

Examples:

from bazi.defines import Tiangan, Wuxing
from bazi.utils.tiangan_utils import he

assert he(Tiangan.甲, Tiangan.丙) is None
assert he(Tiangan.甲, Tiangan.己) is Wuxing.土
assert he(Tiangan.己, Tiangan.甲) is Wuxing.土
bazi.utils.tiangan_utils.chong(tg1: Tiangan, tg2: Tiangan) → bool[源代码]¶

检查输入的两个天干是否构成相冲关系。 返回结果与输入的天干顺序无关，因为相冲关系是无方向的。

Args:

  • tg1: (Tiangan) 第一天干。

  • tg2: (Tiangan) 第二天干。

Return: (bool) 是否相冲。

Examples:

from bazi.defines import Tiangan
from bazi.utils.tiangan_utils import chong

assert chong(Tiangan.甲, Tiangan.丙) is False
assert chong(Tiangan.甲, Tiangan.庚) is True
assert chong(Tiangan.庚, Tiangan.甲) is True
bazi.utils.tiangan_utils.sheng(tg1: Tiangan, tg2: Tiangan) → bool[源代码]¶

检查输入的两个天干是否构成相生关系。 返回结果与输入的天干顺序有关，因为相生关系是单向的。

Args:

  • tg1: (Tiangan) 生的一方。

  • tg2: (Tiangan) 被生的一方。

Return: (bool) 是否 tg1 生 tg2。

Examples:

from bazi.defines import Tiangan
from bazi.utils.tiangan_utils import sheng

assert sheng(Tiangan.甲, Tiangan.丙) is True
assert sheng(Tiangan.丙, Tiangan.甲) is False
assert sheng(Tiangan.庚, Tiangan.甲) is False

检查输入的两个天干是否构成相克关系。 返回结果与输入的天干顺序有关，因为相克关系是单向的。

Args:

  • tg1: (Tiangan) 克的一方。

  • tg2: (Tiangan) 被克的一方。

Return: (bool) 是否 tg1 克 tg2。

Examples:

from bazi.defines import Tiangan
from bazi.utils.tiangan_utils import ke

bazi.utils.tiangan_utils.search(tiangans: Sequence[Tiangan], relation: TianganRelation) → tuple[frozenset[Tiangan], ...][源代码]¶

返回 tiangans 中所有满足该关系的组合。

Note:

  • 只接受 Sequence，非序列在遍历前抛出 TypeError；空序列合法，重复天干不影响结果。

  • 组合不含作用方向，合、冲本身无向；生、克的方向用 sheng / ke 单独判断。 例如组合 {甲, 丁} 本身不表示甲生丁或丁生甲。

Args:

  • tiangans: (Sequence[Tiangan]) 待查天干。

  • relation: (TianganRelation) 待查关系。

Return: (TianganRelationCombos) 所有匹配组合，不包含作用方向。

Examples:

from bazi.defines import Tiangan, TianganRelation
from bazi.utils.tiangan_utils import search

stems = [Tiangan.甲, Tiangan.丙, Tiangan.丁, Tiangan.庚, Tiangan.辛]
assert search(stems, TianganRelation.合) == (frozenset({Tiangan.丙, Tiangan.辛}),)
assert search(stems, TianganRelation.冲) == (frozenset({Tiangan.甲, Tiangan.庚}),)
assert search(stems, TianganRelation.生) == (
  frozenset({Tiangan.甲, Tiangan.丙}), frozenset({Tiangan.甲, Tiangan.丁}),
)
assert search(stems, TianganRelation.克) == (
  frozenset({Tiangan.丙, Tiangan.庚}), frozenset({Tiangan.丙, Tiangan.辛}),
  frozenset({Tiangan.丁, Tiangan.庚}), frozenset({Tiangan.丁, Tiangan.辛}),
  frozenset({Tiangan.甲, Tiangan.庚}), frozenset({Tiangan.甲, Tiangan.辛}),
)
bazi.utils.tiangan_utils.discover(tiangans: Sequence[Tiangan]) → TianganRelationDiscovery[源代码]¶

返回给定天干中所有可能的天干关系组合（合、冲、生、克等）。 各关系由 search 求值。

Note:

  • 返回的字典的键中可能不包含所有的 TianganRelation。

  • 只接受 Sequence，非序列在遍历前抛出 TypeError；空序列合法，重复天干不影响结果。

Args:

  • tiangans: (Sequence[Tiangan]) 待查天干。

Return: (TianganRelationDiscovery) 所有匹配组合的冻结映射，不包含作用方向。

bazi.utils.tiangan_utils.discover_mutual(tiangans1: Sequence[Tiangan], tiangans2: Sequence[Tiangan]) → TianganRelationDiscovery[源代码]¶

找出输入的两组天干中的所有可能的关系组合（合、冲、生、克等）。 返回组合须与两组天干值集均相交，不追踪具体出现；按值过滤语义见 RelationDiscovery.mutual_only。

Note:

  • 返回的字典的键中可能不包含所有的 TianganRelation。

  • 两组输入都须为 Sequence，在遍历任一组前检查；重复天干不影响结果。

Args:

  • tiangans1: (Sequence[Tiangan]) 第一组天干。

  • tiangans2: (Sequence[Tiangan]) 第二组天干。

Return: (TianganRelationDiscovery) 跨组匹配组合的冻结映射，不包含作用方向。

Examples:

from bazi.defines import Tiangan, TianganRelation
from bazi.utils.tiangan_utils import TianganRelationDiscovery, discover_mutual

result = discover_mutual([Tiangan.甲], [Tiangan.己])
assert isinstance(result, TianganRelationDiscovery)
assert result == {
  TianganRelation.合: (frozenset({Tiangan.甲, Tiangan.己}),),
  TianganRelation.克: (frozenset({Tiangan.甲, Tiangan.己}),),
}
empty = discover_mutual([Tiangan.甲, Tiangan.己], [])
assert isinstance(empty, TianganRelationDiscovery) and not empty
