bazi.cli¶

安装版 bazi 命令：展示命盘与关系报告、查询知识、判别前提。

bazi.cli.main(argv=None)[源代码]¶

执行一个命令行任务；未给参数时只显示帮助。

Args:

  • argv: (list[str] | None) 不含程序名的参数；None 表示读取 sys.argv[1:]。

Return: (int) 成功时为 0；参数错误由 argparse 以退出码 2 结束。

Note:

  • TypeError: argv 不是列表或包含非字符串成员。

参数:

argv (list[str] | None)

返回类型:

int
