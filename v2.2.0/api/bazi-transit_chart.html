bazi.transit_chart¶

按年、月、日期或时刻查询命盘流运。

TransitChart 将查询坐标解释为相应的 TransitSet；各入口的支持范围与缺项条件分别说明。

class bazi.transit_chart.TransitChart(bazi_chart)[源代码]¶

查询命盘流运与历法流运的统一入口。

小运、大运来自 TransitDatabase；流年、流月、流日由历法推导。

参数:

bazi_chart (BaziChart)

at_date(solar_date)[源代码]¶

返回东八区无时区公历日期下的流运，出生前或历法范围外返回 None；地点盘出生 下界取规范绝对日期，不取真太阳时日期；大运按物理交运日边界解释。

Args:

  • solar_date: (date) 公历日期，类型须为 date 本身，不接受 datetime 或 date 子类。

Note:

  • TypeError: solar_date 的类型不是 date 本身。

参数:

solar_date (date)

返回类型:

TransitSet | None

at_moment(solar_moment)[源代码]¶

返回东八区无时区公历标签下的流运；后端或命盘精度不支持、出生前、节令表范围外时返回 None。 地点盘出生下界取规范绝对时刻；查询时刻不做地点修正。 查询、出生与大运边界均截到秒比较，相等归新。

Note:

  • 年/月按时刻所属节归属，流日按所选换日点解释；同一公历日可与 at_date() 结果不同。

  • HOUR 原盘归属与秒级时刻流运是两种粒度；相等时辰窗口内可落在不同干支年。

  • solar_moment 不是 datetime 时抛 TypeError；tzinfo 不是 None 时抛 ValueError。

Args:

  • solar_moment: (datetime) 东八区无时区标签，微秒在比较前截去。

参数:

solar_moment (datetime)

返回类型:

TransitSet | None

at_month(gz_year, gz_month)[源代码]¶

返回干支月坐标下的流运，出生前或节令表范围外返回 None； 大运按物理交运月边界解释。

Args:

  • gz_year: (int) 干支年标签。

  • gz_month: (Dizhi) 干支月的地支。

Note:

  • TypeError: gz_year 不是 int，或 gz_month 不是 Dizhi。

参数:

  • gz_year (int)

  • gz_month (Dizhi)

返回类型:

TransitSet | None

at_year(gz_year)[源代码]¶

返回干支年坐标下的流运，早于出生干支年返回 None；大运按命盘所选年份标签视图解释。

Args:

  • gz_year: (int) 干支年标签；远年份仍可返回流年，不以历法表上界截断。

Note:

  • TypeError: gz_year 不是 int。

参数:

gz_year (int)

返回类型:

TransitSet | None
