公历、农历与节气¶

日期换算与节气查询从 bazi.calendar.utils 导入，无需创建命盘。

公历与农历往返¶

from datetime import date

from bazi.calendar.utils import to_lunar, to_date

solar = date(2023, 3, 22)
lunar = to_lunar(solar)
print(lunar)
print(to_date(lunar))
assert to_date(lunar) == solar

(2023-3-1, LUNAR)
2023-03-22

lunar 是不可变的 CalendarDate，有 year、month、day 和 date_type 字段。 农历月号按年内实际月序编号，闰月占独立序号，不是农历月名。 上例的 month=3 是 2023 年的第 3 个月，即闰二月；这一年的 month=4 才是三月。 构造农历输入时也使用同一月序：

from datetime import date

from bazi.calendar.dates import CalendarDate, CalendarType
from bazi.calendar.utils import to_date

leap_month_start = CalendarDate(2023, 3, 1, CalendarType.农历)
assert to_date(leap_month_start) == date(2023, 3, 22)

to_solar 返回公历 CalendarDate，to_date 返回标准库 date； to_lunar 返回农历日期，to_ganzhi 返回以立春换年的干支历日期。 它们都接收 date 或 CalendarDate。传 datetime 时只读年月日，不使用日内时刻，也不换算时区。 to_ganzhi 按交节日划分年月；需要按时辰或分钟判断出生归属时，用 Bazi.create 与 配置与时间口径 中的精度设置。

支持范围¶

from bazi.calendar.dates import CalendarType
from bazi.calendar.utils import get_min_supported_date, get_max_supported_date, to_date

print(to_date(get_min_supported_date(CalendarType.公历)))
print(to_date(get_max_supported_date(CalendarType.公历)))
# 将下面的 CalendarType.农历 换成 CalendarType.干支历，可查干支历端点。
print(get_min_supported_date(CalendarType.农历))
print(get_max_supported_date(CalendarType.农历))

1901-02-19
2099-12-31
(1901-1-1, LUNAR)
(2099-12-20, LUNAR)

日期换算的公历范围为 1901-02-19 至 2099-12-31，包含两端。 CalendarDate 构造时检查字段类型，换算时再检查日期是否合法、是否在支持范围内； 错型抛 TypeError，非法或越界日期抛 ValueError。

查询节气与相邻的节¶

from bazi.calendar.utils import jieqi_moment, prev_jie, next_jie
from bazi.defines import Jieqi

moment = jieqi_moment(2000, Jieqi.立春)
print(moment)
print(prev_jie(moment).jieqi, next_jie(moment).jieqi)

2000-02-04 20:40:23
立春 惊蛰

jieqi_moment 的年份是公历年，可查二十四节气；该年的小寒、大寒都在该年一月。 结果是北京时间的 datetime，不带 tzinfo，截断到秒。prev_jie 和 next_jie 只查开月的十二节， 不含中气，返回 JieqiTime，可读 .jieqi 和 .moment。 恰好交节时，prev_jie 返回当前节，next_jie 返回下一节。

prev_jie、next_jie 也接收这种不带时区的北京时间。用 supported_jie_boundaries() 取得首末节时刻：

from bazi.calendar.utils import supported_jie_boundaries

first, last = supported_jie_boundaries()
print(first)
print(last)

1901-01-06 07:53:29
2200-12-07 16:13:37

prev_jie／next_jie 的输入须在 [first, last) 内，含首端、不含末端，越界抛 ValueError。 jieqi_moment 可查公历 1901 至 2200 年，年份越界也抛 ValueError。 节气能查到 2200 年，日期换算和排盘仍只到 2099-12-31。

数据来源与精度¶

随包表由 celestial-calendar 离线生成， 运行时只读这些表，不联网，也不需要安装生成工具。 农历表在 1901 至 2099 年的月长与香港天文台历书 数据对拍；HKO 原件与解码保留为测试对照。

节气时刻是 UT1 加 8 小时得到的北京时间，1929 年以前也这样算，不换成北京地方平时。 时刻记到秒只是记录格式，不代表误差小于一秒；2101 至 2200 年依赖 ΔT 外推，精度没有保证。 出生归属还受 DAY／HOUR／MINUTE 比较粒度影响，见 配置与时间口径。

来源头、时标和编码约定见历法数据维护所列的数据格式说明。
