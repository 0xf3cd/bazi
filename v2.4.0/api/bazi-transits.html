class bazi.transits.TransitDatabase(chart)[源代码]¶

查询命盘小运、按年份标签解释的大运及按物理边界解释的大运。

_dayun_at_* 是供 TransitChart 使用的包内物理边界入口；调用方先校验坐标、出生下界及 历法可用性，这些入口只解释交运边界，不重复公开入口校验，也不承诺包外调用。

参数:

chart (BaziChart)

dayun(gz_year)[源代码]¶

按命盘年份标签返回干支年坐标 gz_year 的大运。 有限年份视图延伸到末标签后十年，可与末步物理区间不同；视图外返回 None。

参数:

gz_year (int)

返回类型:

Ganzhi | None
