bazi.bazi_chart¶

Bazi 上的命盘派生信息：十神、藏干、纳音、十二长生与运限等。

class bazi.bazi_chart.BaziChart(bazi)[源代码]¶

提供原盘的阴阳五行、十神、十二长生、纳音、藏干等派生信息。 派生量首次访问后缓存；构造后不得重绑 _bazi，重绑不会刷新已有缓存。

property dayun: Generator[DayunTuple, None, None][源代码]¶

从公历交运时刻线生成有限大运；每步覆盖 [start_moment, end_moment)，只生成落在所选历法 后端半开节气窗口内的起点，因此结果可以为空。

Usage:

chart: BaziChart = BaziChart(bazi)

gen = chart.dayun
first_ten_dayuns: list[DayunTuple] = list(itertools.islice(gen, 10))

next_ten_dayuns: list[DayunTuple] = list(itertools.islice(gen, 10))

for dayun in chart.dayun:
  print(dayun.start_moment, dayun.ganzhi)
property dayun_order: bool[源代码]¶

True 代表大运是顺排的，False 代表大运是逆排的。

Note: 传统表述以年干阴阳论「阳男阴女顺、阴男阳女逆」；本实现读年支阴阳，二者数学恒等价—— 六十甲子内干支的阴阳恒一致。

property minggong: Ganzhi[源代码]¶

中气进月的命宫干支，时支取本盘时柱，宫干取本盘年干五虎遁。

依《命理探原》起例按语，现有节月达到中气后月序循环进一；大寒后不提前换年。 中气按出生精度相等归新，地点盘先换真太阳钟。时区与精度政策是本库执行约定， 不称为古籍原文；结果不进入原四柱分析。

property relationship_stars: GanzhiData[Tiangan, tuple[Dizhi, ...]][源代码]¶

夫妻星（配偶星）。

目标干由 BaziSchool.peiou_xing_def 选定（_peiou_xing_target）；地支侧两读一致， 取主气十神等于目标干十神的地支。对固定日主，shishen 在十干上是双射， 「十神相等」与「主气等于目标干」等价。

Usage:

stars = chart.relationship_stars

print(stars.tiangan) # 配偶星天干

print(stars.dizhi)   # 配偶星地支元组
assert 1 <= len(stars.dizhi) <= 2 # 对应一到两个地支

property shishen: BaziData[GanzhiData[Shishen | None, Shishen]][源代码]¶

年、月、日、时柱的天干地支所对应的十神。注意，日主没有十神。

Usage:

shishens = chart.shishen

print(shishens.year.tiangan) # 年干十神
print(shishens.hour.dizhi)   # 时支十神

for idx, pillar_shishens in enumerate(shishens):
  print(pillar_shishens.dizhi) # 此柱地支十神

  if idx == Zhu.日.index: # 跳过日主
    assert pillar_shishens.tiangan is None
    continue
  print(pillar_shishens.tiangan) # 此柱天干十神
