# 十天干语料来源与准入

> 研究范围：issue [#24](https://github.com/0xf3cd/bazi/issues/24) 中
> `TianganDescription` 的进阶解读。本文只判断现有语料的来源层、适用条件和准入方式，
> 不把古籍取象改写成现代人格测验，也不把历史脏腑配属改写成医疗建议。
>
> 对照基线：`bazi/descriptions.py` 在 commit
> [`1398cbc`](https://github.com/0xf3cd/bazi/commit/1398cbc4e8948bec5105b0368831d53058ce75d5)
> 中的 `TIANGAN_DESCRIPTIONS`。公开文本复核日期：2026-09-26。

## 结论

现有语料混合了四种本来不同的内容：十干取象、五行性情、日主旺衰判断和身体配属。
它们不能放在同一个 `general` 或 `personality` 字段里互相作证。

1. 《滴天髓》与《穷通宝鉴》可支持十干在月令、强弱和干支组合下如何作用，不能支持
   “见某天干即有某种固定人格”。
2. 《三命通会》卷七和《渊海子平》确有五行性情文字，但主语是木、火、土、金、水，
   并且明列旺相、休囚、太过、不及等条件。把它平移成甲乙、丙丁各自的无条件人格，
   超出了原文。
3. “太阳、灯烛、城墙、田园、顽铁、珠玉、江河、雨露”有古籍文本依据，但
   《滴天髓阐微》恰好把这种固定比拟称为“比拟失伦”。这些象可作为有出处的流派材料
   保存，不能冒充跨流派定义，更不能直接推出人的性格。
4. 十干配脏腑和身体部位在古籍中存在，而且甲乙配属有明确异文。它最多是历史术数或
   医学配属资料；从“配某脏腑”跳到“容易患病”“须定期检查”没有来源支持，也不应作为
   医疗建议输出。
5. 本批所查来源中，未核到现有大段现代人格句和年度体检建议的可靠出处。这个结论只限于
   下列检索范围，不等于断言这些句子绝不见于任何现代书刊。

## 判定方法

### 三个问题分开判断

每条语料分别回答：

- **系统归属**：四柱命理、一般五行宇宙论，还是医学配属？
- **规则内容**：原文给的是象、性情、调候、格局，还是身体对应？
- **适用条件**：主语是十干、日主、五行，还是某月令和某个具体组合？

一份来源只回答其中一项时，不替它补完另外两项。例如，《五行大义》能证明五行与五常、
五脏相配是一项早期传统，不能因此证明“甲日主必有某性格”或“甲日主容易患肝病”。

### 准入标签

| 标签 | 含义 |
|---|---|
| `admit` | 同一系统中有直接文本支持，且未来语料能保留原文的主语和适用条件。 |
| `variant-only` | 确有来源，但不同文本或流派互相冲突；只能连同来源作为并列变体保存。 |
| `symbolic-only` | 来源只支持取象或配属，不能由此推出人格、吉凶、疾病或现实建议。 |
| `reject-until-sourced` | 本批未见足以支撑当前断言的来源，或来源强度不足以支持用户可见结论。找到符合翻案条件的材料前不准入。 |

`reject-until-sourced` 是语料准入判断，不是“此说必假”的历史断言。

### 来源独立性

S1 与 S5 的五行性情和疾病段落有大段同序、同句文字，现阶段应按同一传承链处理，不能因
两个网页都收录就算“两源互证”。S2、S3、S4 之间也出现相同歌诀和固定措辞；相同措辞只能
证明传承，不自动增加独立性。

## 四条证据边界

### 1. 取象不等于实体定义

S3 的“天干”章直接批评以下做法：

> 比拟失伦，竟以甲木为梁栋，乙木为花果；丙作太阳，丁作灯烛；戊作城墙，己作田园；
> 庚为顽铁，辛作珠玉；壬为江河，癸为雨露。相沿已久，牢不可破，用之论命，诚大谬也。

这不是禁止一切比喻。S3 后文仍用“参天”“藤萝”“天河”等象说明气势；它反对的是把比喻
凝固成干的实体，再从该实体直接推演人格和吉凶。因此：

- “某干在某条件下可借某象解释”可记为 `symbolic-only`；
- 某一文本坚持固定物象、另一文本明确反对时，记为 `variant-only`；
- “因为像某物，所以这个人必然如何”仍是 `reject-until-sourced`。

### 2. 五行性情不等于十干人格

S1“论性情相貌”以五行为主语，并逐项限定强弱。例如木的正文先说：

> 旺相主有博爱惻隠之心慈祥愷悌之意……此則木盛多仁之義

随后又说：

> 休囚主痩長髮少抝性偏心嫉妬不仁……死絶則眉眼不正慳吝鄙嗇……

火、土、金、水也分别列旺相、太过、不及。S5“论性情”沿用相近结构，并在末尾再加
“日干弱”“日干强”的总括。可准入的是“某五行在某状态下，古籍作某种性情判断”，不是
“甲和乙分别拥有两套固定人格”。

S6 还能证明五行配五常本身有异说：正文先列“木仁、金义、火礼、水信、土智”，又指出
毛公、京房及《汉书》系统作“土信、水智”。因此即使是五常配属，也应保留来源，不宜写成
无出处的自然事实。

### 3. 调候不等于性格词表

S4 从“正月甲木”一路分到各干各月。同一个甲木，正月谈余寒和丙癸，三月谈庚壬，
五六月又换成癸、丁、庚的先后；其他九干同样逐月变化。S2、S3 的十干歌诀也不断加入
春秋、燥湿、透藏、坐支和合化条件。

这组材料可直接支持一个独立的“条件化作用／调候”层，不能压缩成“甲积极、乙柔韧、丙热情”
之类静态标签。

### 4. 身体配属不等于疾病预测

S1 的口诀作：

> 甲膽乙肝丙小腸丁心戊胃已脾鄉庚是大腸辛屬肺壬係膀胱癸腎藏

同段身体部位口诀作：

> 甲頭乙頂丙肩求丁心戊脇已屬腹庚是臍輪辛屬股壬脛癸足一身由

S5 当前转录却作“甲肝，乙胆”，身体部位也作“甲头，乙项”。甲乙因此不是可以静默合并的
单一表，而是至少两种版本。S6 只在五行层面列“肝木、心火、脾土、肺金、肾水”，还记录
不同典籍的异配，进一步说明这些是传统配属系统，不是现代解剖或流行病学结论。

S1、S5 后文确有由五行生克推疾病的历史规则，但古代术数文本不能证明现代患病概率，
更不能推出“每年定期做健康检查”。对用户可见语料，身体对应最多保留为带来源、带历史语境
的 `symbolic-only`；疾病风险和检查建议均为 `reject-until-sourced`。

## 对 issue #24 的结构建议

如果后续继续扩展 `TianganDescription`，来源要求支持的最小切分是：

| 内容层 | 应保存什么 | 不应混入什么 |
|---|---|---|
| 基础归属 | 阴阳、五行 | 人格评价。 |
| 取象变体 | 原文短句、来源、注家或版本、适用条件 | 把象写成干的唯一定义。 |
| 条件化作用 | 月令、旺衰、透藏、坐支、合化等前提和结论 | 去掉条件后的标签。 |
| 五行性情 | 五行层面的旺相、休囚、太过、不及及其来源 | 冒充十干各自人格。 |
| 历史身体配属 | 原词、版本异文、历史语境 | 疾病概率、诊断、治疗或体检建议。 |

当前两个字段 `general`、`personality` 无法表达来源层和适用条件。继续往其中增加句子，会使
物象、规则和现实建议更难区分。本文不预先决定 Python API；实现前应先确认是否要在 issue #24
中同时承担来源、条件和流派变体，还是先只清理现有语料。

## 未决项与翻案条件

| 未决项 | 当前结论 | 可翻案条件 |
|---|---|---|
| 现有现代人格句的来源 | 本批所查古籍、网页全文和公开目录中未核到可靠逐句出处。 | 找到可核版本的书刊页，原文明确以对应天干为主语，并给出当前句义和适用条件；只有无来源转载网页不够。 |
| 《穷通宝鉴》的版本链 | 当前页面足以观察逐月结构，不足以裁定《栏江网》、余春台、徐乐吾之间的具体关系。 | 找到可核扫描本的题签、序跋、目录和出版信息，串起文本增删关系。 |
| 《滴天髓》题署与注释归属 | 当前只按页面显示的歌诀、原注、任氏曰分层，不据此断言早期作者。 | 找到可靠版本学研究或早期刻本，并能把具体段落归到相应文本层。 |
| 甲乙脏腑异文 | S1 作甲胆乙肝，S5 当前转录作甲肝乙胆，未裁。 | 取得《渊海子平》可核扫描底本及其他早期本，确认是版本异文还是现代转录误差。 |
| 固定物象能否作为默认值 | S3 有明确反对意见，当前只能并列。 | 用户指定采用某一流派，且该流派的原文与解释链明确把固定物象作为规则，而非讲解比喻。 |
| 疾病和体检建议 | 不准入用户可见命理解读。 | 疾病风险必须有适用于该断言的现代医学证据和产品层面的医疗审查；古籍再多也不能满足此条件。 |

## 检索边界

本批检查了上述 Wikisource 全文，使用简繁体标题、整句和连续片段检索现有现代人格语料，
并查询公开搜索引擎及书目目录。搜索引擎未返回可核的原始出版物；部分目录服务拒绝请求，
Open Library 也未给出目标书的可用记录。因而本文对现代句子使用“本批未核到”，不写成
“古籍不存在”。

Wikisource 页面均是会继续修订的公开转录，本批尚未为每页固定 `oldid`。涉及关键异文时，
下一步应回到扫描底本；在此之前，本文保留短引文和文本层说明，使当前判定仍可复核。
