bazi.analyzer.facts.tonggen(chart: BaziChart, target: Tiangan, transits: TransitSet | None = None, *, condition: TianganMatch = TianganMatch.SAME_WUXING) → tuple[TianganOccurrence, ...][源代码]¶

查目标天干在原局及所选流运的哪些藏干中匹配，默认同五行。

Args:

  • chart: (BaziChart) 原局命盘。

  • target: (Tiangan) 待查天干值，可取任一天干。

  • transits: (TransitSet | None) 同时参与查询的流运；None 只查原局。

  • condition: (TianganMatch) 同干或同五行；错误参数类型抛 TypeError。

Return: (tuple[TianganOccurrence, ...]) 按位置、藏干表顺序返回匹配的实际藏干。

Note:

  • 同五行通根例见《子平真诠》六、论十干得时不旺失时不弱的甲逢未、丙逢戌： https://www.donglishuzhai.net/chapter/3719.html

  • 《滴天髓阐微》才德篇任注亦有庚在酉丑通根的例子： https://www.zhyw.net/a/ditiansui/2020/11/09/23706.html

bazi.analyzer.facts.tougan(chart: BaziChart, target: Tiangan, transits: TransitSet | None = None, *, condition: TianganMatch) → tuple[TouganHit, ...][源代码]¶

查指定藏干在哪些明干处匹配；必须显式选择同干或同五行。

Args:

  • chart: (BaziChart) 原局命盘。

  • target: (Tiangan) 待查的实际藏干值；先按同干定位这个藏干本人，再按 condition 匹配明干。

  • transits: (TransitSet | None) 参与查询的流运；明、藏两端均从原局及所选流运中取。

  • condition: (TianganMatch) 匹配条件，无默认；错误参数类型抛 TypeError。

Return: (tuple[TouganHit, ...]) 藏干位置优先、明干位置次序；保留同柱及同干支不同位置。 无该藏干或无匹配明干时返回空元组。

Note:

  • 辰藏癸而透壬的墓库例见徐乐吾《子平真诠评注》三、论阴阳生死的注文： https://tianjihq.com/zh-CN/learn/books/ziping-zhenquan-pingzhu/14
