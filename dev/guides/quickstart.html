快速开始¶

这一页带你排盘、查看和保存结果。已有 Python 环境就从安装开始；需要新建环境时，可先看页尾的环境准备。

安装¶

需要 Python 3.11 或更高版本。可直接使用已有的 Python、conda、虚拟环境或交互环境。

本页为开发版，下面安装与文档相同提交的源码（需要 Git）：

python -m pip install "git+https://github.com/0xf3cd/bazi.git@e768b414bb1dbaec63bbca224caf038bd2f13e48"

也可下载该提交的源码，在源码根目录运行 python -m pip install .。最近发布版另见版本入口。

运行时只用标准库和随包数据，不联网。普通使用不需要测试或文档构建工具。 终端操作见 命令行；下面使用 Python API，类型从定义模块导入。

排第一张盘¶

示例用虚构的出生时间，按东八区（UTC+8）公历钟填写。默认入口的年月与东八区节气表比较， 日时按输入的钟读取，不自动换算时区；海外当地钟的用法见 配置与时间口径。 BaziChart 在 Bazi 之上提供十神、藏干、纳音和流运等信息。

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart

chart = BaziChart(Bazi.create('1990-05-17 10:30', 'female'))
print('四柱', ' '.join(map(str, chart.bazi.pillars)))
print('日主', chart.bazi.day_master)
print('性别', chart.bazi.gender)

四柱 庚午 辛巳 壬午 乙巳
日主 壬
性别 female

把出生时间换成你的公历出生钟时；也可传无时区的 datetime(年, 月, 日, 时, 分)。 性别接受 男、女、male、female，输出为拉丁写法。 四柱依次为年、月、日、时，日主是日柱的天干。

上例可直接在 Python 交互环境中运行；直接输入 chart 还会看到一行对象摘要。 若喜欢脚本，把程序保存为 UTF-8 文件 show_chart.py，在该文件所在目录运行：

python show_chart.py

两种运行方式都使用刚才安装包的同一个环境。文件不要命名为 bazi.py，以免遮蔽安装包。

查看完整命盘文本¶

basic_text(chart) 返回纯文本，包含出生时刻、四柱十神、阴阳五行、藏干、纳音和十二长生。 下面是完整的独立例子：

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.chart_text import basic_text

chart = BaziChart(Bazi.create('1990-05-17 10:30', 'female'))
print(basic_text(chart).strip())

藏干十神采用单字简称，如财、才、官、杀；完整名称见 Shishen。 文本用于阅读；程序要读取字段时直接使用命盘属性，不解析这些文字，见 集成开发。

保存文本¶

下面把同一张盘存为 chart.txt。路径相对运行代码时的当前目录，重复运行会覆盖同名文件；需保留的旧结果请先另存。

from pathlib import Path

from bazi.bazi import Bazi
from bazi.bazi_chart import BaziChart
from bazi.chart_text import basic_text

chart = BaziChart(Bazi.create('1990-05-17 10:30', 'female'))
path = Path('chart.txt')
path.write_text(basic_text(chart), encoding='utf-8')
print('已保存', path)

已保存 chart.txt

打开 chart.txt 即可阅读。这是展示文本，不是可恢复的命盘记录；以后要重新排盘，保留出生输入和完整配置。 不写 Python 也可用 bazi chart 保存 TXT，见 命令行。

可选：新建环境¶

如果已有合适环境，跳过本节即可。需要单独的工作目录和虚拟环境时，在终端运行：

mkdir bazi-example
cd bazi-example
python -m venv .venv

若系统只提供 python3，创建时用 python3 -m venv .venv。随后按终端激活：

终端

命令

macOS／Linux 的 sh、bash、zsh

. .venv/bin/activate

Windows PowerShell

.venv\Scripts\Activate.ps1

Windows cmd

.venv\Scripts\activate.bat

激活后回到本页“安装”。PowerShell 若不允许激活脚本，可不激活，直接用 .venv\Scripts\python 代替 python；无需修改执行策略。
