bazi.utils.tiangan_utils.search(tiangans, relation)[源代码]¶

返回 tiangans 中所有满足该关系的组合。

Note:

  • 只接受 Sequence，非序列在遍历前抛出 TypeError；空序列合法，重复天干不影响结果。

  • 组合不含作用方向，合、冲本身无向；生、克的方向用 sheng / ke 单独判断。 例如组合 {甲, 丁} 本身不表示甲生丁或丁生甲。

Args:

  • tiangans: (Sequence[Tiangan]) 待查天干。

  • relation: (TianganRelation) 待查关系。

Return: (TianganRelationCombos) 所有匹配组合，不包含作用方向。

Examples:

  • search([甲, 丙, 丁, 庚, 辛], TianganRelation.合):

    • return: ({丙, 辛})

  • search([甲, 丙, 丁, 庚, 辛], TianganRelation.冲):

    • return: ({甲, 庚})

  • search([甲, 丙, 丁, 庚, 辛], TianganRelation.生):

    • return: ({甲, 丙}, {甲, 丁})

  • search([甲, 丙, 丁, 庚, 辛], TianganRelation.克):

    • return: ({丙, 庚}, {丙, 辛}, {丁, 庚}, {丁, 辛}, {甲, 庚}, {甲, 辛})

参数:

  • tiangans (Sequence[Tiangan])

  • relation (TianganRelation)

返回类型:

tuple[frozenset[Tiangan], ...]

bazi.utils.tiangan_utils.discover_mutual(tiangans1, tiangans2)[源代码]¶

找出输入的两组天干中的所有可能的关系组合（合、冲、生、克等）。 返回组合须与两组天干值集均相交，不追踪具体出现；按值过滤语义见 RelationDiscovery.mutual_only。

Note:

  • 返回的字典的键中可能不包含所有的 TianganRelation。

  • 两组输入都须为 Sequence，在遍历任一组前检查；重复天干不影响结果。

Args:

  • tiangans1: (Sequence[Tiangan]) 第一组天干。

  • tiangans2: (Sequence[Tiangan]) 第二组天干。

Return: (TianganRelationDiscovery) 跨组匹配组合的冻结映射，不包含作用方向。

Examples:

  • discover_mutual([甲], [己])

    • return: { TianganRelation.合: TianganRelationCombos({甲, 己},), TianganRelation.克: TianganRelationCombos({甲, 己},) }

  • discover_mutual([甲, 己], [])

    • return: {} // 空的冻结映射。

参数:

  • tiangans1 (Sequence[Tiangan])

  • tiangans2 (Sequence[Tiangan])

返回类型:

TianganRelationDiscovery
