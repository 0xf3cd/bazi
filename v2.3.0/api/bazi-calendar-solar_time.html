bazi.calendar.solar_time¶

使用随库均时差表换算真太阳时。

bazi.calendar.solar_time.apparent_solar_datetime(civil_instant, longitude)[源代码]¶

把固定偏移的民用钟换算为无时区的当地真太阳钟。

经度与时区偏移之差回绕到 [-12h, 12h)，保留出生地区的民用日期基准； 例如西经约 157 度的 UTC+14 民用钟比该子午线提前一日。 换算仍可跨午夜；EOT 为真太阳时减平太阳时，在精确 UTC 瞬间求值。

参数:

  • civil_instant (datetime)

  • longitude (float)

返回类型:

datetime
