bazi.calendar.utils¶

读取预生成 celestial-calendar 表的历法工具，数据契约见 celestial_data/SCHEMA.md。

jieqi_moment 提供秒级真实时刻。CalendarDate 只表示日期，干支历正月初一为立春日； 时刻的四柱归属由调用方决定。农历月号按年内实际月序编号，闰月占独立序号。

返回指定历法的首个支持日期。三种历法共用同一公历窗口。

返回指定历法的最后一个支持日期。

bazi.calendar.utils.to_solar(d: date | CalendarDate) → CalendarDate[源代码]¶

把输入转换为公历 CalendarDate。

Args:

  • d: (date | CalendarDate) 输入日期；date 按公历解释，datetime 只取自身的年月日，不换算时区。

Return: (CalendarDate) SOLAR 类型日期。

bazi.calendar.utils.to_lunar(d: date | CalendarDate) → CalendarDate[源代码]¶

把输入转换为农历 CalendarDate。

Args:

  • d: (date | CalendarDate) 输入日期；date 按公历解释，datetime 只取自身的年月日，不换算时区。

Return: (CalendarDate) LUNAR 类型日期，月号按年内实际月序编号，闰月占独立序号。

bazi.calendar.utils.to_ganzhi(d: date | CalendarDate) → CalendarDate[源代码]¶

把输入转换为干支历 CalendarDate。

Args:

  • d: (date | CalendarDate) 输入日期；date 按公历解释。

Return: (CalendarDate) GANZHI 类型日期。

Note: datetime 是 date 子类，只取自身的年月日，不换算时区，同日各时刻的结果相同。 此入口只按日期归属；出生比较粒度由 BaziPrecision 决定。

bazi.calendar.utils.to_date(d: date | CalendarDate) → date[源代码]¶

把输入转换为公历 date。

Args:

  • d: (date | CalendarDate) 输入日期；datetime 只取自身的年月日，不换算时区。

Return: (date) 公历日期。

bazi.calendar.utils.jieqi_moment(solar_year: int, jieqi: Jieqi) → datetime[源代码]¶

输入公历年份和节气，返回节气的具体时刻。

Args:

  • solar_year: (int) 公历年。

  • jieqi: (Jieqi) 节气。

Note:

  • 时刻为东八区（北京时间），精度到秒（截断）。1929 年前同样按东八区表达， 而非北京地方平时。

Return: (datetime) 指定公历年的节气时刻。

bazi.calendar.utils.supported_jie_boundaries() → tuple[datetime, datetime][源代码]¶

返回首末支持节的时刻元组。prev_jie / next_jie 的输入须在这两个时刻之间， 含首端、不含末端。

bazi.calendar.utils.prev_jie(dt: datetime) → JieqiTime[源代码]¶

返回不晚于输入公历时刻的最近一节及其时刻，不含中气；恰交节归该节（比较为 >=）。

Args:

  • dt: (datetime) 待查时刻。

Return: (JieqiTime) 所属节及其公历时刻。

bazi.calendar.utils.next_jie(dt: datetime) → JieqiTime[源代码]¶

返回严格晚于输入公历时刻的最近一节及其时刻，不含中气；恰交节时继续查下一节（比较为 >）。

Args:

  • dt: (datetime) 待查时刻。

Return: (JieqiTime) 下一节及其公历时刻。
