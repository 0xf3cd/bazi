bazi.context_matching.evaluate_context(chart: BaziChart, *, criterion_id: str, observation: NatalObservation | LiunianObservation | TransitObservation) → ContextResult[源代码]¶

检查选定范围是否满足已注册判据，返回判别、观察、证据及参考条目 ID。

Note:

  • NatalObservation 供所有判据共用；LiunianObservation 用于原局加单流年观察， TransitObservation 用于婚恋结构的多种岁运查询。不支持的观察种类抛 ValueError。

  • 各判据的事实定义及 entry_role 见 criteria()。premise 判据检查关联条目的完整前提， condition 判据只检查局部事实；判据未包含的条件须另读知识条目。 判别不判断喜忌，也不会因未计算这些条件而返回 UNKNOWN；所需流年缺失或不可查询时返回 UNKNOWN。

  • 条件判据的关联条目只是条件参考， 与事实判别的状态无关；只向男命返回的关联条目对女命一律不关联，静态查阅不受限。

  • 观察原局年、月、时明干与四支全部实际藏干；请求流年时加入该流年明干与藏干。 不观察日主明干，但等于日主的藏干仍分类为比肩；藏干百分比不作权重，重复位置保留。 不另加力量／次数阈值、相邻、去留或有效制化条件。

  • 范围完整性优先于女命条件与事实判别：男命缺必需年份仍为 UNKNOWN / missing_transit_coordinate。 婚恋范围缺查询坐标为 UNKNOWN / missing_transit_coordinate；入口不可查询或所求种类 部分缺失为 UNKNOWN / transit_unavailable，已取得种类的证据照常保留。 SATISFIED / NOT_SATISFIED 只描述当前判据声明的事实，不证明现实事件成立。

  • 关联按稳定 claim ID，不比较文字或来源摘要；自定义库负责同 ID 的领域含义。 编辑正文、引文或来源说明不改变判据状态；UNKNOWN 是判据的状态，不是参考条目的状态。

  • reference_ids 按声明序与性别门槛给出，不检查知识库是否收录；正文须由调用方显式查阅。

Return: (ContextResult) 判据结果、逐柱观察或结构证据、参考条目 ID 与命盘输入。
