bazi.calendar.utils_protocol¶

历法后端共同遵循的接口协议。

CalendarUtilsProtocol 描述日期换算、节气和支持范围查询，不选择具体后端。

class bazi.calendar.utils_protocol.CalendarUtilsProtocol(*args, **kwargs)[源代码]¶

历法工具共用的协议，成员为实例方法，以支持后端的实例状态，见 #86。 CelestialCalendarUtils 为每种阴历算法各建一个实例；HKO 则是模块函数， 运行时结构满足协议，但 mypy 不识别，解析分支须用 cast，见 calendar_utils_of。

jieqi_moment 的精度随后端不同：HKO 只发布节气日期，用当日午夜占位； celestial 提供秒级真实时刻。其余日期级接口按相同契约互换。

prev_jie / next_jie 始终查询真实时刻：交节日午夜至真实交节之间，HKO 的午夜占位与 天文后端可返回不同节。出生精度归属属于 Bazi：DAY 从日期级干支年月选择开月节和下一节， 不改变此物理通道。大运即使使用同一所属节，仍可因后端节时刻不同而得到不同起点。 日期级差异继续受冻结白名单约束（见 tests/calendar/celestial_parity_data.py）。
