class bazi.bazi.Bazi(birth_time, gender, config=DEFAULT_CONFIG, *, longitude=None, civil_timezone=None)[源代码]¶

存储年、月、日、时四柱及排盘基本信息。十神、大运等派生信息见 bazi_chart.py 的 BaziChart。

Note:

  • 默认路径直接采用无时区民用时刻；传入 longitude 才会从调用方给定的带时区时刻换算真太阳时。

  • 本库从立春派：年柱以立春换年，不以正月初一（春节）换年。

参数:

  • birth_time (datetime)

  • gender (BaziGender)

  • config (BaziConfig)

  • longitude (float | None)

  • civil_timezone (tzinfo | None)

static create(birth_time, gender, config=DEFAULT_CONFIG, *, longitude=None, civil_timezone=None)[源代码]¶

从出生输入创建 Bazi。

Args:

  • birth_time: (datetime | str) 公历出生时刻；字符串经 datetime.fromisoformat 解析。 未给经度时须无时区，给定经度时须带时区。

  • gender: (BaziGender | str) 性别枚举，或 "男"/"女"/"male"/"female"（大小写不敏感）。

  • config: (BaziConfig) 出生精度、历法后端、流派档案及大运年份投影； 可用 BaziConfig.from_values 从字符串构造。

  • longitude: (float | None) 东经为正的经度，显式启用带时区输入的真太阳时路径；不使用纬度。

  • civil_timezone: (tzinfo | None) 显式出生地民用时区基准；模型保存其在出生瞬间生效的固定偏移。

参数:

  • birth_time (datetime | str)

  • gender (BaziGender | str)

  • config (BaziConfig)

  • longitude (float | None)

  • civil_timezone (tzinfo | None)

返回类型:

property month_jies: tuple[JieqiTime, JieqiTime][源代码]¶

按 self.config.precision 归属的开月节与下一节，供年/月柱和大运数节共同使用。

Note:

  • [0] 是出生月所属节，[1] 是其下一节，均保留后端原始节时刻。

  • DAY 的整个交节日归新；HOUR/MINUTE 按各自粒度相等归新。提前归属窗口中， 所属节的真实时刻可以在出生之后；逆排大运的负间隔钳为零。

  • 真实出生时刻前后节仍应以 reference_datetime 查询历法 prev_jie / next_jie。

static random(config=DEFAULT_CONFIG, *, rng=None)[源代码]¶

随机生成一个 Bazi，主要用于测试。

Note:

  • 年份范围为 [1902, 2080]，日期范围为 [1, 28]。

  • 指定局部 rng 可重放样本且不改变全局随机状态；省略时沿用 random 模块的种子语义。

Args:

  • config: (BaziConfig) 命盘级配置，传给 Bazi.create。

  • rng: (Random | None) 局部随机源；None 使用 random 模块。

Return: (Bazi) 随机八字。

参数:

  • config (BaziConfig)

  • rng (Random | None)

返回类型:

property reference_datetime: datetime[源代码]¶

节表、大运及流运查询的出生参考时刻。

地点盘返回保留秒/微秒的 naive UTC+08 标签；默认盘返回分钟截断的民用标签。 此坐标不是真太阳钟，也不改变出生精度的归属规则。

class bazi.bazi.LocationTime(canonical_instant, civil_time, longitude, apparent_time)[源代码]¶

模型返回的不可变地点时间事实；时间值不经 JSON 解析或重复换算。
