bazi.calendar.celestial_utils¶

读取预生成 celestial-calendar 表的历法工具，数据契约见 celestial_data/SCHEMA.md。 满足 CalendarUtilsProtocol，不依赖 HKO 工具；两后端独立实现，一致性由测试核对。

jieqi_moment 提供秒级真实时刻，HKO 则用午夜占位。CalendarDate 仍只表示日期： 干支历正月初一为立春日。时刻的四柱归属由调用方决定（#72）。

两种阴历算法各有一个模块级单例，缓存不能混用。若用可变模块开关配合 lru_cache， 切换后可能返回旧算法的缓存结果；独立实例把算法选择纳入工具对象身份。
