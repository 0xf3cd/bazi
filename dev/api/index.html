API 参考¶

按要完成的任务选择入口；完整模块索引在下方。函数签名给出类型，Args / Return 说明参数与结果的含义。 示例可整块运行：带输出的代码后紧随 text 对照，其余代码用 assert 写出预期结果。

排盘、配置与文本¶

  • bazi.bazi.Bazi 创建八字，bazi.bazi_chart.BaziChart 读取四柱与派生结果。

  • bazi.school.BaziConfig 和 bazi.school.BaziSchool 选择精度、历法与流派。

  • bazi.chart_text 输出命盘文字；终端调用见 命令行。

关系、神煞与流运¶

  • bazi.utils.tiangan_utils、bazi.utils.dizhi_utils 查询单组关系或搜索组合。

  • bazi.utils.shensha_utils 查单项神煞，bazi.analyzer.relationship 读取命盘分析。

  • bazi.transit_chart.TransitChart 按年、月、日期或时刻查询流运； bazi.analyzer.facts 保留通根、透干的具体位置。

知识、出处与前提匹配¶

  • bazi.knowledge.KnowledgeBase 查条文与出处；按中文名浏览见 知识目录。

  • bazi.context_matching 查判据、选择观察范围并求值；操作步骤见 集成开发。

  • bazi.rules 给出规则表及定义选项，表值按键查阅，不在页面展开全部内容。

历法、领域值与结果结构¶

  • bazi.calendar 选择历法后端，bazi.calendar.utils_protocol 说明两后端的共同接口。

  • bazi.defines 定义天干、地支等领域值；bazi.data_types 定义四柱数据容器。

  • bazi.utils.bazi_utils 提供十神、纳音、藏干等纯查询。

  • 公开接口契约 说明对象身份、输入校验与结果不可变性。

离线数据工具¶

以下入口用于在源码仓重建随库表，不是排盘或修复安装的步骤；安装版缺表应重新安装。 构建文档只导入这些模块读取说明，不执行下载或生成入口。

  • bazi.calendar.hko_data.encoder 下载并编码 HKO 历书；下载时另需 requests。

  • bazi.calendar.celestial_data.generator 生成 celestial 数据；另需与 bazi.calendar.celestial_data.generator.CELESTIAL_VERSION 一致的 celestial-calendar。
