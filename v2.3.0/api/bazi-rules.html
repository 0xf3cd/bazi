问真《神煞大全》与高人不作两个独立来源计数。 两家引同一首口诀时引得一样，汉字序列全同，只是标点习惯不同；这本身说明不了什么—— 口诀是公共财产，况且两家并不总挑同一首（见下文天乙）。 但有几处断语也长段逐字相同——断语是各家自撰的评断文字， 本无必须一致的理由，那确实指向共享文本。反方向的事实同时存在：多数断语除了 三五个字外毫无共同处，而且两家读法有分歧——天乙各择一个歌诀版本 （高人并自述用的是哪一个），红艳问真作乙午而高人作乙申，即下面 HONGYAN 已记的散文本／歌诀本之分。

国印贵人的查法定义。两读都取该干禄位的固定偏移（含禄起算），只在偏移量上分歧。

  • WUXING_JINGJI：禄 + 7，见《五行精纪注释》及下引恬裕斋抄本国印条的禄前第八位。

  • MODERN：禄 + 8，果老一脉的禄前第九位，也是现代通行表。

默认 MODERN，表值与《张果星宗》及此处所引现代来源一致。

两读无一格重合：每个天干在两读下各得不同地支，故命中结果不会含混。

各来源的结论与限度：

  • 《张果星宗》的「禄勋、阳刃、唐符、国印」条载「禄前八位号唐符，第九名为国印宫」， 并逐干举例：「甲禄到寅、卯为阳刃、酉为飞刃唐符，戌为国印。乙禄到卯、 辰为阴刃、戌为飞刃唐符、亥为国印……」。同书「天干吉凶星例」表载 「国印：主掌印，戌亥丑寅丑寅辰巳未申」，十格相同。 条目例解与「天干吉凶星例」表共同支持 MODERN。例解明确含禄起算：甲禄在寅，酉为第八、戌为第九。

  • 《星学大成》「唐符禄前八位是 国印禄前九位是」为该对联的散文形； 《神峰通考》将两星归于果老一脉（「惟张果老通玄先生命理 专用此二星 取贵」）。 按《张果星宗》例解的含禄起算法，「禄前九位」即禄 + 8，与 MODERN 同表；不据此裁定传承关系。

  • WUXING_JINGJI 依《五行精纪注释》卷十三【原文】： 「国印星禄前第八位是，如甲申生人，至癸酉是。并《三命纂局》」。同页今人【注释】作： 「国印星，命局见年干禄前第八位的地支，如甲申生人，甲禄在寅，寅前八位是酉」。 年干锚与含禄起算的明文出自今人【注释】，不混作【原文】的断言。 目录著录为恬裕斋清抄本的第二册图像 81-82 分列建節星与國印星，后者作「祿前第八位是如甲申生人至癸酉是」。 此引文只及该见证，不证明宋代原貌或今人注释所据底本。 两份白文转录的【建节星】则作「禄前第六位是也，如甲申生人，至癸酉是也」，与抄本及注释本有异， 传抄关系未定（#194）。

  • WUXING_JINGJI 与 FEIREN[YangrenDef.LUMING] 十格相同；同格不裁定传抄关系。

  • 查找位置与表值分开： 《星学大成》明言「守照身命」，即命宫身宫而非四柱， 《张果星宗》亦作「唐符、国印守命为奇」；所引《神峰通考》段落未言查找位置。 本库按四柱地支查的做法依此处所引现代来源，不出自上述段落。

太极贵人的查法定义。两读只在壬癸分歧。

  • REN_GUI_BOTH：壬癸各兼巳申。

  • REN_SI_GUI_SHEN：壬取巳、癸取申。

《五行精纪》一句并存两读，以「一作」引出第二读；此「一作」是同书异文，不是两家表之争：

壬巳癸申一作壬癸巳申偏喜美，封侯万户即三公

默认 REN_GUI_BOTH 取歌诀「一作」所指读法，也是现代两家所取。

两处原文问题保留如下：

  • 《三命通会》两处数字转录（taiyi、算准网）作「壬癸水先得则生， 后得巳而纳」，维基文库四库全书本作「壬癸水先得申而生後得巳而納」。 高人引文与本节对应句式均有申。 故该字为申，「则」是那两处转录的讹，不是这部书的异文。

  • 同节作「戊己，土也，喜生乎申，得辰戌丑未为正库」。按句式申应属戊己格， 但问真、高人与《五行精纪》均只列四库；无来源可裁，表从三家，矛盾如实留档。

文昌的查法定义。两读只在辛一格分歧，其余九干在所查各来源中相同。

  • XIN_ZI：辛 → 子。

  • XIN_XU：辛 → 戌。

默认取 XIN_ZI：民国刊本与现代主流两条谱系都指向它。XIN_XU 出自《星学大成》。

本表为子平法文昌（食神之临官、长生），与下方禄命法文昌贵分列； 第三颗文星贵（「甲马乙蛇丙戊猴」）未纳入本库。

出处限度：

  • 《命理探源》散文只逐条列甲乙丙丁戊己，末句「庚辛壬癸仿此」。 后四干见所引口诀（「庚猪辛鼠壬逢虎，癸人见兔入云梯」），辛取子依据口诀而非散文。

  • 《星学大成》口诀作辛戌，散文说明（「独辛不以生而以戌为文昌，戌在辛之方位」）， 因此 XIN_XU 是自成一说，不是抄讹。

class YangrenDef(*values)[源代码]¶

羊刃（阳刃）与飞刃共用的三种定义。羊刃分歧在阴干有无刃及刃位；每套飞刃均取 对应羊刃定义的对冲支。

  • ZIPING：子平法，仅五阳干有阳刃。

  • LUMING：古禄命法，十干皆有羊刃，取禄前一辰。

  • DIWANG：十干各取帝旺位；现代问真与高人皆采用此表，两家按一份来源计， 见 ShenshaRules 的 docstring。

飞刃：

  • ZIPING：仅五阳干有飞刃，取阳刃对冲支。

  • LUMING：十干皆有飞刃，取古禄命羊刃对冲支。

  • DIWANG：十干各取帝旺位的对冲支。

BaziSchool.yangren_def 与 BaziSchool.feiren_def 独立，可任意组合羊刃与飞刃定义。
