class bazi.analyzer.relationship.RelationshipEvidence(star_target, appearances, house_relations, star_relations, stem_relations, transits)[源代码]¶

一次婚恋结构查询的可核证据。

序号契约：house_relations／star_relations／stem_relations 的组合成员共享一个序列—— 原局四柱为 0–3，所选岁运按 TransitSet.items 的固定顺序自 4 起；组合的范围由序号直接分出 （全部 < 4 为原局内部，全部 ≥ 4 为岁运内部，其余为原局×岁运）。本类没有 scope 字段， 不声称它能单独检查范围；跨字段约束归拥有 observation 与 evidence 的 ContextResult。

transits 是实际取得的所选岁运；原局、无坐标或全部缺失时为 None。

bazi.analyzer.relationship.spouse_evidence(chart, transits)[源代码]¶

计算一次婚恋结构查询的可核证据；只读结构与位置，不判婚恋吉凶。

求值分四段：非拱关系对 原局＋岁运 完整序列一次求值（序号天然全局）；拱局分原局内部 （相邻、所拱之支不在原局）、原局×岁运（跨组柱位对）、岁运内部（相邻、局部序号 +4）三段。 拼接后序列里的所拱之支会填实全部拱局，使本成立的单侧拱局消失，因此不能一次拼接。 三段都不被另一侧填实抑制。

过滤：宫证据为组合含序号 2（日柱这一具体出现，不以同值地支代替柱位）；星证据为组合中任一 参与者的地支属配偶星地支；天干侧为明干组合含目标干。证据不投影，保留完整干支与序号。

Args:

  • chart: (BaziChart) 待查命盘；取法与关系定义读自其流派配置。

  • transits: (TransitSet | None) 实际取得的所选岁运；None 表示只查原局。

Return: (RelationshipEvidence) 目标、出现与三类关系证据。

参数:

  • chart (BaziChart)

  • transits (TransitSet | None)

返回类型:

RelationshipEvidence
