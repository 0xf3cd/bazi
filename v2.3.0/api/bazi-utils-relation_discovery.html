bazi.utils.relation_discovery¶

关系查询结果的不可变映射容器。

RelationDiscovery 保存关系种类及其命中组合，供天干、地支查询共用。

mutual_only(items1, items2)[源代码]¶

只保留与两侧值集均相交的组合；与任一侧不相交即单侧组合。

Note: 按值判定，不追踪具体出现：组合全由单侧凑成，只要另一侧也有相同值，就会被保留。 discover_mutual([子, 丑], [子]) 仍保留六合{子,丑}（子出现在两侧值集里，尽管一侧就够凑）。

参数:

  • items1 (Set[RelationItemType])

  • items2 (Set[RelationItemType])

返回类型:

Self
