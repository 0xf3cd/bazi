frozendict 提供冻结映射；check_declared_types 校验声明类型。

浅冻结的不可变映射：映射本身不可变，取值原样返回，不做防御性拷贝。 持有可变值的一方须在自己的边界防止外部修改。

参数:

data (Mapping[FrozenDictKeyType, FrozenDictValueType])

bazi.common.check_declared_types(instance)[源代码]¶

逐字段核对运行时类型，第一个不符合声明类型的字段抛 TypeError。 用于构造函数为公开入口的 frozen 值类型；校验依据字段注解，新增字段也会被检查。

Note:

  • 由 __post_init__ 调用；值域检查（范围、成员、跨字段规则）留在调用处，本函数只检查类型。

  • 字段注解必须是运行时类或它们的联合，不能是延迟注解或参数化泛型。 不满足此条件的 dataclass 须自行校验。

Args:

  • instance: (DataclassInstance) 待检查的 dataclass 实例，通常为 self。

参数:

instance (DataclassInstance)

返回类型:

None
